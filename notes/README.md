# Notes

This directory holds pre-spec working notes. `retrieval-theory.md` is
a Japanese-language scratch document (~800 lines) written while
working out the retrieval-related design decisions later formalized
in [`theory/retrieval.md`](../theory/retrieval.md) and rationale
entries R13–R16 in [`spec/99-rationale.md`](../spec/99-rationale.md).

Most of its content (roughly 80%) has since been superseded by
`theory/retrieval.md`, which is the normative-adjacent, English,
maintained companion document. This file is **not** part of the
specification and is **not** kept up to date; it is retained for
provenance — to let future readers trace how the ISF/level-hierarchy
ideas in `theory/retrieval.md` were originally worked out.

If you're looking for the current theoretical background, read
`theory/retrieval.md` instead.
