# Changelog

One line per version, extracted from `spec/99-rationale.md` §History,
which remains the canonical record of *why* each change was made.

- **v0.2.0** — Adds Chapter 03 (Operations), Chapter 05 (Errors), and
  the `conformance/` test matrix (L1–L4b); adopts transaction-owned
  operations, distinct `attributes`/`filters`, `neighbors` depth
  policy, relevance-as-implementation-defined, and renames L4b from
  "Semantic" to "Intent"; adds the non-normative `theory/retrieval.md`
  companion.
- **v0.1.0** — Initial release. Establishes Node/Edge/Actor/
  Transaction/Event as the five first-class concepts, the
  L_source/L_concept/L_category layer system, reserved kinds and
  relations, and the exclusion of sources from the retrieval space.
